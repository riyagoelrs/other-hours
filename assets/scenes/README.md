# Other Hours worktable

`worktable.svg` is original scene art made for Other Hours: a pink timer, orange thread spool, green book and a short strand of beads. It uses vector shapes, material shading and cast shadows. `worktable-mobile.svg` keeps the timer and book so the mobile search area stays clear. Neither file includes external resources, scripts, reference artwork or an actual timer/clock status.

The enclosing native button opens a guide from the real catalog. Pointer and native-scroll transforms are applied to the scene by `scene.js`; the artwork contains no looping animation. Reduced-motion mode keeps it static while preserving the guide action.
