# Other Hours activity photography

Self-hosted Pexels photographs illustrate hobbies, materials and creative company. **They are not photographs of the NYC directory’s venues, group members or a guaranteed finished result from a guide.** Voluntary photographer links are in the footer.

The photos were previously retrieved for this project on 2026-11-18. Selected originals are reused unchanged in the 2026-11-20 design. JPEG files are copied from those retained source downloads; WebP files are restored from the earlier repository assets. No generated people, synthetic craft images or reference-site artwork is used. CSS crops the presentation; the source file bytes are retained.

Pexels permits free use and modification under its [license](https://www.pexels.com/license/). Source records for the clay, jewelry, collage, painting and group imagery were retained in the earlier research. When no individual photographer was retained, the source page carries its credit.
